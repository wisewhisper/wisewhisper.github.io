평균 가속도 실험실

ā = Δv / Δt = (v₂ − v₁) / (t₂ − t₁)

물체 크기·화살표 길이는 설명용입니다. 위치 눈금은 조건에 맞춰 자동 조정되며, 화면 이동은 계산한 위치에 따릅니다.

② 변수 조작 · 실시간 계산

조건을 바꾸면 재생 시각은 0초로 돌아갑니다. 두 모형은 처음·나중 속도가 같고 평균 가속도도 같습니다.

③ 속도–시간 그래프

실선: 선택한 모형의 순간 속도 · 노란 점선: 양 끝점을 잇는 직선 · 흰 점: 현재 상태. 점선 기울기 = 평균 가속도. A·B 저장 시 같은 축으로 겹쳐 표시합니다.

기호와 단위

v₁: 측정 시작 속도, v₂: 측정 종료 속도, Δv: 속도 변화, Δt: 양수인 시간 간격, ā: 평균 가속도. 1 m/s²는 1초당 속도 변화가 1 m/s라는 뜻입니다.

⑤ 예측 → 조작 → 관찰 → 설명

기본 · v₁ = 0, v₂ = 12 m/s에서 시간을 4초에서 8초로 늘리면?

ā는 3 m/s²에서 1.5 m/s²로 절반이 됩니다. 같은 속도 변화에 시간이 두 배 걸리면 평균 가속도는 절반입니다.

응용 · v₁ = −2, v₂ = −10 m/s, Δt = 4 s일 때 빨라질까요?

ā = −2 m/s²입니다. 속력은 2에서 10 m/s로 증가합니다. 속도와 가속도가 모두 왼쪽을 가리킬 때 속력이 증가합니다. 가속도가 음수라는 사실만으로 감속이라고 판단할 수 없습니다.

도전 · 처음과 끝 속도가 같으면 내내 등속 운동일까요?

아닙니다. ‘평균 0 · 중간 변화’를 누르세요. v₁ = v₂ = 5 m/s이지만 곡선 모형에서는 중간에 속도가 9 m/s까지 증가했다가 돌아옵니다. 평균 가속도 0은 두 끝 속도가 같다는 뜻입니다.

오개념 · 평균 가속도와 순간 가속도는 항상 같다?

등가속도일 때는 같습니다. 곡선 모형으로 바꾸고 시각을 이동하면 순간 가속도는 변하지만 전체 구간의 평균 가속도는 그대로입니다. 속도–시간 그래프에서 순간 가속도는 접선 기울기, 평균 가속도는 두 점을 잇는 직선의 기울기입니다.

적용 조건 · 이 실험의 운동 모형

평균 가속도 정의는 가속도가 일정하지 않아도 적용됩니다. 이 실험은 고정된 좌표축의 1차원 운동이며, 초기 위치 x(0) = 0 m입니다. 등가속도 모형은 v(t)=v₁+āt, x(t)=v₁t+½āt²입니다. 곡선 모형은 v(t)=v₁+āt+4sin(πt/Δt), x(t)=v₁t+½āt²+(4Δt/π)[1−cos(πt/Δt)]이며 속도의 추가 진폭은 4 m/s입니다. 실제 힘이나 마찰을 재현한 모형은 아닙니다. Δt=0이면 평균 가속도를 정의할 수 없어 시간은 0.5초 이상으로 제한했습니다.
