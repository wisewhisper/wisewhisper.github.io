열역학 제1법칙

ΔU = Q − W

열을 전달하거나 기체의 부피를 바꾸면 내부 에너지는 어떻게 변할까?

부호 약속: Q > 0 기체가 받은 열 · W > 0 기체가 외부에 한 일 · ΔU > 0 내부 에너지 증가

① 피스톤 속 기체

8초 재생은 과정의 진행을 보여주는 연출 시간입니다. 열전달률이나 피스톤의 실제 속도를 뜻하지 않습니다.

② 조건 조작

조건을 변경하면 진행률은 0으로 돌아갑니다. 저장한 A·B 조건은 유지됩니다.

③ 실시간 에너지 회계

받은 열 Q
기체가 한 일 W
내부 에너지 변화 ΔU

에너지 막대: 가운데 0, 오른쪽 양수, 왼쪽 음수. 세 막대에 동일한 눈금을 적용합니다.
기호와 계산 모형

기체를 계로 잡습니다. U는 내부 에너지, Q는 열전달, W는 경계가 움직이며 기체가 외부에 한 일입니다. 모두 단위는 J입니다. T는 절대 온도(K), V는 부피(m³), P는 압력(Pa), n은 몰수(mol)입니다.

단원자 이상 기체: PV = nRT, U = (3/2)nRT, Cᵥ = (3/2)R, γ = 5/3, R = 8.314 J/(mol·K). 준정적 과정에서 W = ∫P dV입니다.

정압: W = P(V − V₀). 정적: W = 0. 등온: W = nRT₀ ln(V/V₀), ΔU = 0. 단열: TV^(γ−1) = 일정, Q = 0, W = −ΔU.

항목AB

⑥ 예측 → 조작 → 관찰 → 설명

먼저 에너지 변화의 부호를 예상한 뒤 조건을 바꾸고, 그래프와 계산값으로 설명해 보세요.

기본 탐구 · 정적 가열에서 받은 열은 어디로 갈까?

정적 과정을 선택하고 온도 변화 +100 K로 설정하세요. W는 왜 0일까요?

해설: 부피 변화가 없으므로 경계 일이 0입니다. 따라서 ΔU = Q이며 받은 열은 모두 내부 에너지 증가에 해당합니다. 1 mol이면 Q = 1.5 × 8.314 × 100 = 1247.1 J입니다.

응용 탐구 · 등온 팽창인데 왜 열을 받아야 할까?

등온 과정에서 최종 부피비를 2로 설정하세요. Q, W, ΔU를 비교하세요.

해설: 이상 기체의 내부 에너지는 온도에만 의존하므로 ΔU = 0입니다. 팽창하며 한 일만큼 열을 받아야 온도가 일정합니다. Q = W = nRT ln 2. 온도가 일정해도 열전달이 0인 것은 아닙니다.

도전 탐구 · 열을 주지 않고 기체를 뜨겁게 만들 수 있을까?

단열 과정에서 최종 부피비를 0.5로 설정하세요. 온도와 W의 부호를 관찰하세요. 몰수를 2배로 하면 에너지 값은?

해설: 압축에서는 W < 0이므로 ΔU = −W > 0입니다. T/T₀ = 2^(2/3) ≈ 1.587이 됩니다. 같은 초기 온도·부피·부피비에서는 몰수를 2배로 하면 압력, W, ΔU가 2배이지만 온도비는 같습니다.

오개념 확인

“압축할 때 기체가 한 일도 양수이다” → 부피비를 1보다 작게 바꾸면 W < 0입니다. 외부가 기체에 한 일은 −W입니다.

“단열은 온도가 일정하다는 뜻이다” → 단열 팽창에서 Q = 0이지만 W > 0이므로 온도가 내려갑니다. 등온과 단열을 같은 부피비로 A·B 저장해 비교하세요.

“열은 기체 안에 저장된 물질이다” → Q는 경계를 통과해 전달된 에너지이며 상태량 U와 구분합니다.

적용 조건과 모형의 한계

몰수가 일정한 단원자 이상 기체와 마찰 없는 피스톤을 가정합니다. 각 상태를 평형으로 볼 수 있는 준정적 과정이며 운동·위치 에너지 변화는 무시합니다. 정압 과정은 일정한 외부 하중, 정적 과정은 피스톤 고정, 등온 과정은 열저장고 접촉, 단열 과정은 열적으로 절연된 벽을 전제로 합니다.

기체와 피스톤의 그림은 축척을 조절한 개념도입니다. 입자 점은 기체 표시용이며 실제 분자 수나 경로가 아닙니다. P–V 그래프는 수치 축을 사용합니다. 이 모형을 실제 공기(이원자 기체)에 그대로 적용하면 비열비가 달라 오차가 생깁니다.
