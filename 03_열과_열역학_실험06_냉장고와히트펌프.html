냉장고와 히트펌프 실험실

전기적 일로 저온 열원에서 고온 열원으로 열을 이동시키는 원리를 관찰합니다.

실험 조건

조건을 변경하면 해당 실험을 초기화합니다. 실험 완료 후 결과가 유지됩니다.

실시간 측정값

냉매 순환

증발기(저압, 열 흡수) → 압축기(일 입력) → 응축기(고압, 열 방출) → 팽창 장치(압력 감소) → 증발기. 냉매의 실제 압력·엔탈피는 냉매 종류와 운전 조건에 따라 달라집니다.

에너지 보존

QH = QC + W. 냉방 COP = QC/W, 난방 COP = QH/W. COP가 1보다 커도 에너지를 만들어 내는 것은 아닙니다.

카르노 한계와 실제 모형

냉방 COP의 한계는 TC/(TH−TC), 난방 한계는 TH/(TH−TC). 실제 모형의 냉방 COP는 카르노 한계에 설정 비율을 곱하며, 난방 COP는 여기에 1을 더합니다. 실제 제품 성능 예측이 아닌 교육용 모형입니다.

탐구 순서

조건 하나를 바꾸기 전에 결과를 예측하세요. 시작하여 장면과 측정값을 관찰하고, 결과 보기로 최종 상태를 확인하세요. 초기화 후 한 조건만 바꾸어 비교하세요. 표시된 수치는 가상 모형의 계산값입니다.
