주기와 진동수

T = 1/f

진동수를 바꾸면 한 번 진동하는 데 걸리는 시간은 어떻게 달라질까?

① 예측 → 진동 관찰

진동수를 2배로 높이면 주기는 어떻게 될까? 먼저 예측한 뒤 오른쪽 조작부에서 확인하세요.

위상 원 1회전과 왕복 진동 1회가 대응합니다. 실제 물체가 원을 따라 이동한다는 뜻은 아닙니다.

실험 시간 t
완료한 진동 수
현재 변위 x

재생 속도는 화면의 시간 흐름만 바꿉니다. 계산한 f와 T는 바뀌지 않습니다.

② 조작과 실시간 계산

범위: 0.20~4.00 Hz

T: 1회 진동에 걸리는 시간(s)
f: 1초당 진동 횟수(Hz = s⁻¹)
A: 최대 변위(m), N: 진동 횟수(무차원)

진동수·주기·진폭을 변경하면 시간을 0으로 되돌리고 일시정지합니다.

여러 번 진동해 주기 측정하기

측정 전 · T = Δt/N, f = N/Δt

0초에서 시작해 N회 진동 후 자동 정지합니다. 일시정지·재생은 측정 구간을 유지합니다.

③ 그래프로 관계 읽기

변수 관계 · 진동수와 주기

가로축 f를 변화시켜 T = 1/f를 계산합니다. 진폭과 무관합니다.

시간 변화 · 변위

현재 조건에서 x(t) = A cos(2πft). 최근 5초를 표시하며, 처음에는 0~5초를 표시합니다. 흰 점은 현재 상태입니다.

시간이 5초를 넘으면 그래프 구간이 함께 이동합니다. 현재 조건과 저장 조건을 같은 시간축에서 비교합니다.

④ 조건 A·B 비교

두 조건 모두 x(0) = +A, 왼쪽으로 진동을 시작합니다. 그래프에서 A는 노란 파선, B는 분홍 점선입니다.

동일한 5초 구간에서 비교 · N₅ = 5f (정수가 아닐 수 있는 진동 수)
조건f (Hz)T (s)A (m)N₅

⑤ 예측 → 조작 → 관찰 → 설명

기본

f = 1 Hz를 A에 저장하고 f = 2 Hz를 B에 저장해 보세요. 5초 동안의 진동 수와 주기는 각각 어떻게 달라지나요?

해설 펼치기

A: T = 1 s, 5초에 5회. B: T = 0.5 s, 5초에 10회. 진동수는 2배, 주기는 절반이 됩니다.

응용

f = 0.8 Hz로 8회 자동 측정하세요. 측정 시간이 얼마인가요? T = Δt/N으로 다시 확인하세요.

해설 펼치기

Δt = N/f = 8/0.8 = 10 s, T = 10/8 = 1.25 s입니다. 한 번보다 여러 번의 진동 시간을 측정하면 실제 실험에서 시간 측정의 상대 오차를 줄이는 데 도움이 됩니다.

도전

f를 고정하고 A를 0.25 m에서 0.50 m로 바꿔 보세요. 그래프와 주기는 어떻게 변하나요? +A에서 −A까지 이동하는 시간은 한 주기인가요?

해설 펼치기

이 모형에서 진폭이 2배가 되면 변위 그래프의 높이는 2배가 되지만 T는 같습니다. +A에서 −A까지는 T/2입니다. 한 주기를 세려면 위치와 운동 방향이 함께 반복되어야 합니다. 실제 진동계에서는 진폭에 따라 주기가 달라질 수도 있습니다.

⑥ 오개념과 적용 조건

“주기가 클수록 진동수도 크다?”

반비례 관계입니다. 주기 조절 모드에서 T를 1 s → 2 s로 바꾸면 f는 1 Hz → 0.5 Hz가 됩니다. 항상 fT = 1입니다.

“평형점을 한 번 지날 때마다 진동 1회?”

한 주기에 평형점을 두 번 지납니다. +A에서 출발해 평형점, −A, 평형점, +A로 되돌아오는 전체 과정이 1회 진동입니다.

적용 조건·모형의 한계

T = 1/f는 일정하게 반복되는 주기 운동에 적용합니다. 장면은 진폭과 진동수가 일정한 이상적인 사인파 진동이며 감쇠와 외력을 별도로 계산하지 않습니다. 특정 용수철·진자의 질량이나 길이로 진동수를 결정하는 모형은 아닙니다. 진폭 변화가 주기에 영향을 주지 않는 것은 이 실험의 설정입니다.

장면의 수평 축은 ±1 m에 해당하는 고정 축척으로 그리며 원은 위상을 설명하는 개념도입니다. 그래프의 물리량·시간은 SI 단위로 표시합니다. f = 0은 주기적인 진동이 없고 유한한 T를 정의할 수 없어 입력 범위에서 제외했습니다. 두 독립 모드 모두 f 0.2~4 Hz, T 0.25~5 s 범위입니다.
