31. 전기 용량

C = Q / V

전압과 극판의 면적·간격을 바꾸면, 저장되는 전하량과 전기 용량은 어떻게 변할까요?

예측 → 조작 → 관찰 → 설명

평행판 축전기 실험

전하 기호의 개수와 화살표 길이는 비교용 표현입니다. 극판·간격은 확대 표시하며 실제 축척과 다릅니다.

전기 용량 C
왼쪽 극판 전하 Q
전위차 V

전하량–전압 관계 그래프

시간 그래프가 아닙니다. 현재 A, d, εᵣ를 고정하고 전압을 가상으로 변화시킵니다. 기울기는 C이며, 점은 현재 상태입니다.

현재: 실선 · 조건 A: 점선 · 조건 B: 긴 점선. 저장 조건은 각 조건의 구조를 고정한 직선으로 표시합니다.

조건 조작

먼저 예측해 보세요: 전압만 2배로 높이면, C도 2배가 될까요?

조건 A · B 비교

물리량조건 A조건 B

각 조건의 전원 상태·구조와 실제 계산값을 함께 저장합니다.

공식과 기호

C: 전기 용량(F, 패럿)
Q: 한쪽 극판의 전하량(C, 쿨롱)
V: 두 극판 사이 전위차(V, 볼트)

평행판 모형: C = ε₀εᵣA/d
ε₀ = 8.854 × 10⁻¹² F/m
A: 마주 보는 면적(m²), d: 간격(m), εᵣ: 상대 유전율

1 nF = 10⁻⁹ F · 1 nC = 10⁻⁹ C
1 cm² = 10⁻⁴ m² · 1 mm = 10⁻³ m

부호와 0 V 처리

여기서는 Q를 왼쪽 극판의 부호 있는 전하, V를 왼쪽 전위 − 오른쪽 전위로 정의합니다. 오른쪽 전하는 −Q입니다. Q와 V의 부호가 같아 C는 항상 양수입니다. 통상 크기로 표현하면 C = |Q|/|V|입니다.

V = 0이면 Q = 0이므로 0/0은 계산할 수 없습니다. 이때도 구조로 결정되는 C는 그대로이며, Q–V 그래프의 기울기로 구할 수 있습니다.

탐구 질문 · 펼쳐 보는 해설

기본 — 전압을 4 V에서 8 V로 바꾸면?

전원을 연결하고 구조를 고정해 조작하세요. Q = CV이므로 전하량은 2배가 되지만 C는 변하지 않습니다. 기본 구조에서 C ≈ 0.1771 nF, Q는 약 0.7083 nC에서 1.4166 nC로 변합니다.

응용 — 극판 간격을 1 mm에서 2 mm로 바꾸면?

C = ε₀εᵣA/d이므로 C는 절반입니다. 전원 연결 상태에서는 V가 일정하므로 Q도 절반입니다. 전원을 분리하면 Q가 일정하므로 V가 2배가 됩니다. 같은 구조 변화라도 연결 상태에 따라 결과가 달라집니다.

도전 — 전원을 분리한 뒤 상대 유전율을 2배로 높이면?

Q는 일정하고 C는 2배가 되어 V는 절반입니다. E = V/d도 절반이 됩니다. 저장 에너지 U = Q²/(2C)는 절반이 됩니다. 반대로 전원에 연결하면 V가 일정하고 Q와 U = ½CV²가 2배가 됩니다. 에너지 교환의 상대는 전원 및 유전체를 넣는 외부 작용입니다.

오개념 확인 — 전기 용량은 전하량 자체인가요?

전기 용량은 단위 전압당 저장되는 전하량을 나타냅니다. 같은 축전기에 전압을 다르게 걸면 Q는 변하지만 C는 같습니다. 전압을 0 V로 만들고 전기 용량 표시와 그래프 기울기를 확인하세요.

적용 조건과 모형의 한계

이상적인 평행판, 균일한 선형 유전체, 정전 평형을 가정합니다. 가장자리 전기장, 누설, 절연 파괴, 유전체의 비선형성 및 충·방전 과도 과정은 다루지 않습니다. 간격이 극판 가로 길이보다 충분히 작을 때 평행판 근사가 적합합니다. 전원 분리 시 양쪽 극판 전하가 각각 보존됩니다. 구조를 바꾸면 최종 평형 상태를 즉시 표시합니다.

전기장 화살표는 양전하 극판에서 음전하 극판 방향을 나타냅니다. 정적인 관계 실험이므로 재생 버튼은 없습니다.
