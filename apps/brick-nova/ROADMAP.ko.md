# BRICK NOVA v1.0 이후 버전별 개발 계획

v1.0은 두 월드, 20개 스테이지, 보스 2종의 첫 정식판이다. 캠페인, 90초 타임어택, 무한 도전, 보스전을 제공한다. 아래는 10개 월드·100개 스테이지·보스 10종까지 확장하는 제안이며, 출시 일정은 플레이 테스트 결과를 보고 정한다.

## v1.1 — 용암 지대 · 30판 / 보스 3종

- 연쇄 폭발의 순서가 길을 바꾸는 월드. 온도가 다른 구역을 오가며 어떤 폭탄을 먼저 터뜨릴지 고르게 한다.
- 초반은 연쇄 순서를 한 번에 이해할 수 있게 하고, 중반부터 먼저 연 길에 따라 공략이 갈리게 한다. 보스는 외부 냉각 장치를 맞혀 잠깐 열린 핵을 공격한다.
- 검증할 점은 첫 시도에서 반응의 원인을 알아볼 수 있는지, 다른 순서로 시작해도 진행 가능한지, 연속 폭발에 공이 가려지지 않는지다.

## v1.2 — 얼음 지대 · 40판 / 보스 4종

- 감속 구역을 조준의 이점으로 활용한다. 결빙 표적, 녹는 길, 느린 구간과 빠른 구간을 조합한다.
- 보스는 이동 속도가 빠른 분신과 느린 실체를 궤적으로 구분하도록 설계한다.
- 실제 터치로 감속 경계의 입력 반응을 확인하고, 마지막 벽돌을 쫓는 시간이 과도하게 늘어나는 배치를 줄인다.

## v1.3 — 기계 공장 · 50판 / 보스 5종

- 이동 방어벽과 컨베이어가 반복할 때 타이밍을 읽는 월드. 앞선 장치로 후속 통로를 여는 판과, 움직이는 표적을 맞히는 판을 구분한다.
- 보스는 회전하는 모터의 노출 순서를 읽어 순서대로 정지시킨다.
- 50판의 막힘과 중복 공략을 점검한다. 실기기 측정에서 프레임과 발열을 기록하고 모바일 그래픽 강도를 조정한다.

## v1.4 — 심해 관측소 · 60판 / 보스 6종

- 방향이 바뀌는 해류를 이용해 공의 옆 방향 속도를 바꾼다. 고정된 안전 통로를 이용하거나 해류를 타고 멀리 있는 표적을 노릴 수 있게 한다.
- 보스는 물살이 바뀌기 전에 위치를 예고하고, 반대 방향의 흐름을 이용해 측면을 노리게 한다.
- 스킬 없이도 가능한 기본 공략과 흡인·반발을 활용한 빠른 공략을 각각 검증한다.

## v1.5 — 궤도 정거장 · 70판 / 보스 7종

- 흡인·반발 외에 방향이 바뀌는 중력장을 도입한다. 각 중력원의 영향 범위를 가시화하고, 어느 장치를 먼저 지나갈지 선택하게 한다.
- 보스는 두 중력원 사이에 교대로 약점을 노출한다.
- 벡터 처리의 프레임 독립성과 에너지 고갈 상태에서의 복구 가능성을 확인한다.

## v1.6 — 번개의 사원 · 80판 / 보스 8종

- 번개에 연결된 대상과 스위치의 순서를 예고한다. 짧은 연쇄로 보호막을 열거나, 한 번에 긴 연쇄를 만들도록 판별 목표를 나눈다.
- 보스는 여러 도체를 순서대로 연결해 차폐를 해제한다. 해금한 보스들을 이어서 상대하는 보스 러시를 추가한다.
- 번개의 대상과 효과음이 여러 개 겹쳐도 남은 목표를 읽을 수 있는지 확인한다.

## v1.7 — 블랙홀 지대 · 90판 / 보스 9종

- 포털 출구 방향과 궤도 굴절을 조합한다. 출구 표시를 먼저 익히고, 후반에는 한 번의 반사로 포털을 연속 통과하는 판을 둔다.
- 보스는 출구가 바뀌기 전에 위치를 예고한다. 플레이어가 같은 포털에 갇히지 않도록 공의 상태와 복귀 경로를 점검한다.
- 장시간 무한 도전의 난이도, 배치 중복 빈도, 일시정지와 복귀를 확인한다.

## v1.8 — 노바 코어 · 100판 / 보스 10종

- 마지막 월드는 용암·얼음·기계·중력·번개·포털 중 몇 가지를 한 판에서 조합한다. 각 판의 목표와 사용할 기술을 눈에 띄게 안내한다.
- 최종 보스는 방어막 파괴, 이동 약점 공략, 노바 활용의 단계로 구성한다.
- 전 월드 진행, 기록 이전, 보스 해금, 공개 링크, 오프라인 패키지를 통합 검증한다. 고해상도·고주사율과 다채널 오디오는 지원 장비에서의 측정 결과에 맞춰 제공 범위를 정한다.

## 모든 업데이트에 공통으로 적용할 계획

- 스테이지를 여러 개 생성한 뒤 목적과 공략이 겹치는 배치는 걸러낸다. 각 판의 시작 화면과 진행 표시에는 지금 달라진 것과 남은 목표를 보여준다.
- 새 월드는 기본 규칙 소개 → 조합 → 변형 → 보스 순으로 구성한다. 중반 판끼리도 목표, 장애물, 조작 타이밍 중 적어도 하나가 실제로 달라지게 한다.
- 새 규칙이 열쇠 파괴 후에도 풀리지 않는 경우, 좁은 틈에서 공이 갇히는 경우, 마지막 벽돌에 도달할 수 없는 경우를 자동화로 점검한다. 재미와 체감 난이도는 여러 판을 이어 하는 사람의 플레이로 확인한다.
- 캠페인 해금과 모드별 기록 저장 호환성을 유지하고, 공개 페이지의 실행과 오프라인 ZIP을 매 출시마다 확인한다.
