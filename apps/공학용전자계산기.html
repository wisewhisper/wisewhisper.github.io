사용 방법

DEG는 도(°), RAD는 라디안입니다. SHIFT를 누른 뒤 sin·cos·tan을 누르면 역삼각함수가 입력됩니다. 노란 보조 기능은 한 번 사용하면 해제됩니다.

MR: 메모리 불러오기 · MS: 현재 값 저장
M+: 현재 값을 메모리에 더하기
SHIFT + MR: 메모리 초기화 · Ans: 직전 답
S↔D: 소수와 근사 분수 전환 (분모 최대 10,000)
EXP: ×10의 거듭제곱 입력 (예: 6.02 EXP 23)

버튼 사용 시 휴대폰 키보드는 열리지 않습니다.
직접 입력하려면 액정 아래 ‘키보드 입력 켜기’를 누르세요.
Enter: 계산 · Esc: 수식 초기화
괄호는 직접 닫아 주세요. %는 앞의 값을 100으로 나눕니다. 음수의 제곱은 (-3)^2처럼 괄호로 묶어 주세요.

실제 공학용 계산기의 키 구성을 참고한 독자 디자인입니다. 실수 범위의 수치 계산을 지원하며, 일반 결과는 최대 12자리 유효숫자로 표시합니다. 기록·메모리는 사용 중인 브라우저에 저장됩니다. 상단 패널은 장식입니다.
