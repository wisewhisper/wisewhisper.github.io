0 페이지PDF는 기기에 파일로 저장 · 보관 문서는 이 브라우저에서 다시 열기

이미지 PDF 또는 OCR 텍스트를 포함한 검색 PDF를 만듭니다. 수정한 글자는 선택 위치가 사진과 다를 수 있습니다. 책 양면 분리·그림자 완화를 지원합니다. 한글·영문 글자 추출을 지원합니다. 수동 글줄 펴기를 지원합니다. 가로 글줄 기반 자동 보정값 제안을 지원합니다. 실제 3D 복원은 지원하지 않습니다. 팩스는 외부 앱 전달만 지원하며 실제 발송은 해당 앱에서 진행합니다.
자동 검출은 단순 배경에서 가장 잘 작동합니다. 결과를 확인하고 수동으로 조정하세요.
사진은 이 기기에서 처리합니다. 내 문서는 이 브라우저에 저장되며 브라우저 데이터 삭제 시 사라집니다. 중요한 문서는 PDF로 내려받으세요.
