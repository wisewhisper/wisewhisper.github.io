교류 → 자기 선속 변화 → 유도 전압

01 · 원리 읽기

1차 코일에 교류를 공급하면 철심을 지나는 자기 선속 Φ가 변합니다. 이 변화가 2차 코일에 전압을 유도합니다. 두 코일은 전선으로 직접 연결되지 않습니다.

V₂ / V₁ = N₂ / N₁ = n

N: 감은 수(회), V: 전압 실효값(V). 같은 선속 변화가 각 코일을 지나므로 감은 수가 많을수록 전압이 큽니다.

I₂ / I₁ = N₁ / N₂ = 1/n

이상적인 경우 평균 전력은 P₁ = P₂ = V₂I₂입니다. 전압을 올리면 같은 전력을 전달하는 전류는 줄어듭니다.

왜 전압이 생길까요?패러데이 법칙: ε = −N dΦ/dt. 마이너스 부호는 유도 효과가 선속 변화를 방해하는 방향임을 뜻합니다. 그래프의 v₁, v₂는 대응 극성(점 표시)에 맞춘 단자 전압이며, v₁ = N₁ dΦ/dt로 정의합니다.

모델: 정현파 교류, 완전 결합, 손실 없는 철심·코일, 저항 부하. 여자 전류·누설 자속·포화는 제외합니다. 실제 변압기에서는 발열과 손실이 발생합니다.

02 · 철심과 두 코일 관찰

2차 실효 전압
2차 실효 전류
전달 평균 전력

철심의 화살표는 Φ의 방향과 크기입니다. 코일의 움직이는 점은 교류의 방향을 보여주는 개념 표현이며 전자의 실제 이동 속도는 아닙니다. 코일 그림은 실제 감은 수를 축약했습니다.

05 · 예측하고 확인하기

① N₂를 두 배로 하면?V₂는 두 배입니다. 부하 저항을 그대로 두면 I₂도 두 배, 전력은 네 배가 됩니다. 전류가 반으로 줄어드는 관계는 1차와 2차 사이의 관계입니다.
② 주파수를 두 배로 하면?전압과 감은 수가 같으면 최대 선속은 반으로 줄어듭니다. Φ최대 = √2 V₁/(2πfN₁). 이 이상 모델에서 전압비는 그대로입니다.
③ 직류를 연결하면?지속적으로 변하는 선속이 없어 정상 상태에서 2차 전압이 유도되지 않습니다. 연결·차단 순간은 예외입니다. 실제 1차 코일에는 큰 전류가 흘러 과열될 수 있습니다.
