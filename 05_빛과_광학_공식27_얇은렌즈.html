얇은 렌즈: 빛이 모여 만드는 상

1/f = 1/do + 1/di

물체 거리와 초점거리를 바꾸면 상의 위치·크기·방향이 어떻게 달라질까요?

① 예측 → 광선 관찰

물체는 렌즈 왼쪽에 놓입니다. 실선은 실제 광선, 점선은 역방향 연장선입니다.

위 버튼은 수렴 렌즈(f = +0.20 m) 대표 조건을 설정합니다.

② 조건 조작

정적인 광학 모형입니다. 입력을 바꾸면 즉시 다시 계산하며, 거리와 높이는 m 단위를 사용합니다.

실시간 계산

상 거리 dᵢ
배율 M
상 높이 hᵢ
상의 성질

dᵢ = fdₒ/(dₒ − f), M = hᵢ/hₒ = −dᵢ/dₒ

실물체: dₒ > 0 · 실상: dᵢ > 0 · 허상: dᵢ < 0. h > 0은 광축 위쪽, M < 0은 도립입니다.

③ 물체 거리–상 거리 관계

④ 같은 기준으로 조건 비교

조건f (m)dₒ (m)dᵢ (m)M상의 성질

A·B는 저장 순간의 값입니다. 현재 그래프의 초점거리와 다른 조건은 그래프에 겹쳐 표시하지 않습니다.

⑤ 예측 → 조작 → 관찰 → 설명

기본 · f = 0.20 m, dₒ = 0.60 m이면 상은 어디에 생길까요?

dᵢ = 0.30 m, M = −0.50. 렌즈 오른쪽에 도립·축소된 실상이 생깁니다. 스크린 거리를 0.30 m로 맞춰 확인하세요.

응용 · 물체를 2f에서 f 쪽으로 옮기면 상은 어떻게 변할까요?

dₒ > f인 범위에서 물체가 초점에 가까워질수록 dᵢ와 |M|이 커집니다. dₒ = f이면 나온 광선이 평행하여 유한한 거리에 상이 맺히지 않습니다. 렌즈 공식은 단순 비례 관계가 아닙니다.

도전 · 발산 렌즈에서 실물체로 실상을 만들 수 있을까요?

f < 0, dₒ > 0이면 dᵢ = fdₒ/(dₒ − f) < 0이고 0 < M < 1입니다. 이 조건의 단일 발산 렌즈는 항상 정립·축소 허상을 만듭니다. 가상 물체나 복합 렌즈는 이 모형의 범위 밖입니다.

오개념 · 허상은 빛이 실제로 모이는 곳인가요?

허상 위치는 실제 광선의 역방향 연장선이 만나는 곳입니다. 스크린을 오른쪽 어느 곳에 두어도 허상을 직접 맺을 수 없습니다. 수렴 렌즈에서 dₒ를 0.10 m로 바꾸어 점선을 확인하세요. 또한 렌즈가 수렴 렌즈라고 항상 실상이 생기는 것은 아닙니다.

적용 조건과 모형의 한계

두께를 무시한 렌즈와 광축에 가까운 근축 광선의 기하광학 모형입니다. 공기 중에서 렌즈 양쪽 매질이 같다고 가정하며 수차·회절·렌즈의 유한한 구경은 다루지 않습니다. 화면의 광선은 관계를 보여주는 개념도이며 큰 각도에서는 정량적 실제 광선 추적을 의미하지 않습니다. 가로와 세로 축척은 각각 고정하며, 크기 비교를 쉽게 하도록 세로를 확대했습니다. 물체와 상의 높이에는 같은 세로 축척을 적용합니다. 광선의 화면 각도는 실제 각도와 다릅니다. 화면 밖의 상은 수치로 안내합니다. 스크린 표시의 초점 일치 허용 오차는 0.005 m이며 실제 선명도의 모형은 아닙니다.
