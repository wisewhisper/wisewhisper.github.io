열평형과 열량 보존

두 물체를 열접촉시키면 온도가 높은 물체에서 낮은 물체로 열이 순이동합니다. 단열되어 있고 상변화가 없으면 두 시료가 주고받은 열량의 합은 0입니다.

QA + QB = 0
Tf = (mAcATA0 + mBcBTB0) / (mAcA + mBcB)

열용량 mc가 큰 시료의 온도는 상대적으로 적게 변합니다. 초기 온도가 같으면 순열전달은 없습니다.

비열 비교

비열은 물질 1 kg의 온도를 1 K 높이는 데 필요한 열량입니다.

Q = mcΔT　→　ΔT = Q/(mc)

같은 질량에 같은 열량을 공급하면 비열이 작은 물질의 온도 변화가 더 큽니다.

비열: 물 4186, 알루미늄 900, 철 452, 구리 387 J/(kg·K).

열접촉과 모형의 한계

열전달률은 G(TA−TB)로 가정합니다. G가 커지면 평형에 더 빨리 접근하지만 최종 평형 온도는 같습니다. 계산은 각 시료 내부의 온도가 균일하고 외부 열손실 및 용기의 열용량이 없다고 가정합니다.

τ = CACB / [G(CA+CB)],　C = mc

6τ에서 시뮬레이션을 종료하며 남은 온도 차이는 처음의 약 0.25%입니다. 화면 속 점은 에너지 전달의 상징이지 이동하는 열입자가 아닙니다. 그림과 시간은 실제 장치의 정밀 예측이 아닙니다.

탐구 순서

  1. 초기 조건에서 평형 온도를 예측하고 시작합니다.
  2. 질량을 바꾸고 같은 온도 조건에서 결과를 비교합니다.
  3. 열접촉 정도 G를 바꾸어 최종 온도와 도달 시간을 비교합니다.
  4. 비열 비교 탭에서 동일 질량·열량으로 온도 변화를 비교합니다.
