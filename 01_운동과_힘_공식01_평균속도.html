평균 속도는 변위, 평균 속력은 이동 거리

01. 핵심 공식

평균 속도 v̄ = Δx / Δt = (x끝 − x시작) / (t끝 − t시작)

평균 속력 = 전체 이동 거리 / 걸린 시간

평균 속도는 방향을 가진 벡터, 평균 속력은 음수가 될 수 없는 스칼라입니다. 단위는 모두 m/s이며 |평균 속도| ≤ 평균 속력입니다.

02. 왕복 운동

0 m → 10 m → 0 m, 각 5초: 변위 0 m, 이동 거리 20 m, 평균 속도 0 m/s, 평균 속력 2 m/s.

첫 5초의 평균 속도는 +2 m/s, 다음 5초는 −2 m/s입니다. 두 구간의 평균 속력은 모두 2 m/s입니다.

03. 네 가지 그래프 읽기

위치–시간: 측정 시작·끝을 잇는 할선의 기울기는 평균 속도.

속도–시간: 부호를 포함한 넓이는 변위.

속력–시간: 넓이는 이동 거리.

누적 이동 거리–시간: 할선의 기울기는 평균 속력.

04. 시간 가중평균

0 → 8 → 0 m를 각각 2초, 8초 동안 이동하면 속도는 +4, −1 m/s입니다.

단순 산술평균 +1.5 m/s와 달리 전체 평균 속도는 (4×2−1×8)/10 = 0 m/s입니다. 평균 속력은 16/10 = 1.6 m/s입니다.

05. 직접 탐구

같은 경로에서 시간을 2배로 늘리면?

기본 조건의 변위 +8 m는 동일하고 전체 시간이 10초에서 20초로 늘어나 평균 속도는 +0.8에서 +0.4 m/s로 감소합니다.

같은 변위에서 이동 거리만 달라지면?

A·B 비교 예시에서 두 자동차의 변위는 +8 m, 시간은 10초이므로 평균 속도는 +0.8 m/s로 같습니다. B는 되돌아와 이동 거리가 더 큽니다.

음의 평균 속도는 느리다는 뜻일까?

아니요. 부호는 선택한 양의 방향과 반대임을 뜻합니다. 속력은 속도의 크기입니다.

06. 모형의 가정과 한계

1차원 점입자의 두 구간 등속 운동입니다. 경유 순간 속도가 바뀌는 이상화 모형이며, 두 구간 속도가 다르면 경유 순간의 순간 속도는 정의하지 않습니다. 실제 자동차의 가속·감속 과정은 모형에서 생략했습니다.

자동차 크기, 화살표 길이는 표시용이며 위치 눈금은 고정됩니다. 재생 배율은 표시 시간만 바꿉니다. Δt=0이면 평균 속도와 속력은 정의하지 않습니다.
