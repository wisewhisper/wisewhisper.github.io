물리 공식 40 · 인터랙티브 실험실 · 고2

01 평균 속도

v̄ = Δx / Δt

경로와 측정 구간을 바꾸면 평균 속도와 평균 속력은 어떻게 달라질까?

1. 예측하고 운동 관찰하기

직선 위에서 출발 → 경유 → 도착. 오른쪽이 + 방향입니다.

시작을 누르거나 현재 시각을 이동하세요.

경로·시간을 바꾸면 운동이 0초로 돌아갑니다. 측정 구간 변경은 운동을 재시작하지 않습니다.

2. 조건 조작

측정 구간 선택

0 ≤ 시작 < 끝 ≤ 전체 운동 시간. 최소 구간은 0.1초입니다.

위치: −20~20 m · 각 구간 시간: 0.5~20 s

3. 측정 구간의 결과

평균 속도
평균 속력
변위 Δx
이동 거리

측정값은 선택한 구간의 모형 계산값입니다. 재생이 끝나기 전에도 표시됩니다. 평균 속도는 방향을 포함하며, 평균 속력은 이동 거리/시간입니다.

4. 위치–시간 그래프

실선: 운동의 x(t) · 주황 점선: 측정 시작·끝을 잇는 할선 · 채운 점: 현재 위치. 할선의 기울기가 평균 속도입니다.

5. 조건 A·B 비교

경로와 측정 구간을 함께 저장합니다.

조건측정 구간 (s)변위 (m)거리 (m)평균 속도 (m/s)평균 속력 (m/s)

공통 시간·위치 축을 사용합니다. A: 파란 실선·원 / B: 보라 점선·사각형. 각 조건의 측정 시작·끝을 표시합니다.

6. 예측 → 조작 → 관찰 → 설명

기본 탐구 · 시간을 2배로 늘리면?

기본 조건에서 두 구간 시간을 모두 2배로 바꾸세요. 변위와 평균 속도는 어떻게 바뀔까요?

해설 보기전체 구간을 측정하면 변위는 +8 m로 같고 시간은 10 s → 20 s입니다. 평균 속도는 +0.8 → +0.4 m/s로 절반이 됩니다.
응용 탐구 · 왕복 운동의 평균 속도는?

‘왕복’을 누르고 전체 구간과 첫 구간(0~5초)을 비교하세요. 평균 속도와 평균 속력이 같나요?

해설 보기전체 10초의 변위는 0 m, 거리는 20 m입니다. 평균 속도는 0 m/s, 평균 속력은 2 m/s입니다. 첫 5초에는 둘 다 2 m/s입니다. 5~10초 평균 속도는 −2 m/s이고 평균 속력은 2 m/s입니다.
도전 탐구 · 구간 속도들의 단순 평균은 맞을까?

출발 0 m, 경유 8 m, 도착 0 m, 첫 시간 2 s, 둘째 시간 8 s로 설정하세요. 두 구간 속도의 산술평균과 전체 평균 속도를 비교하세요.

해설 보기두 구간 속도는 +4, −1 m/s입니다. 산술평균은 +1.5 m/s지만 전체 평균 속도는 0 m/s입니다. 시간 가중평균 (4×2 + (−1)×8)/10을 사용해야 합니다.
오개념과 확인 방법

“평균 속도는 항상 양수다” → ‘음의 변위’를 선택해 부호를 확인하세요.

“이동 거리를 시간으로 나누면 평균 속도다” → 왕복 운동에서 변위 0과 거리 20 m를 비교하세요.

“평균 속도는 매 순간의 속도다” → 왕복에서 현재 점의 기울기와 전체 할선 기울기를 비교하세요.

기호 · 적용 조건 · 모형의 한계

Δx = x(끝) − x(시작), Δt = 끝 시각 − 시작 시각 > 0. v̄의 SI 단위는 m/s입니다. 원점은 x=0, 오른쪽이 +입니다.

평균 속도 정의는 가속도가 일정하지 않아도 적용됩니다. 여기서는 1차원 점입자가 각 구간에서 일정한 속도로 움직입니다. 경유점의 순간적인 속도 변화는 이상화이며 실제 물체는 유한한 시간에 방향을 바꿉니다. 꺾이는 순간의 순간 속도는 정의하지 않습니다.

공간은 경로 범위에 맞춰 자동 축척됩니다. 물체와 화살표 크기는 실제 크기가 아닙니다. 재생 배율은 관찰 시간만 바꾸며 물리 계산값에는 영향을 주지 않습니다. 입력의 빈 값·비수치 값은 직전 값으로 복원됩니다.
