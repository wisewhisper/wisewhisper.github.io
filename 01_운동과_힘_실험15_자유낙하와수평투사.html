같은 시간에 두 물체의 연직 위치와 연직 속도는 같습니다.

오른쪽·아래쪽을 양(+)으로 설정. 충돌 시 속도는 직전 값입니다. 조건 변경 시 시간을 초기화합니다.

핵심 원리 · 두 운동은 서로 독립적이다

같은 높이 h에서 A는 정지 상태로 놓고, B는 초기 수평 속도 v₀로 던집니다. 두 물체의 초기 연직 속도는 0이며, 공기 저항을 무시하고 균일한 중력만 고려합니다. 오른쪽과 아래쪽을 양의 방향으로 정합니다.

01. 자유낙하 A

x = 0, y = ½gt²

vₓ = 0, vᵧ = gt

aₓ = 0, aᵧ = g

연직 등가속도 직선 운동을 합니다.

02. 수평 투사 B

x = v₀t, y = ½gt²

vₓ = v₀, vᵧ = gt

합성 속력 = √(v₀² + g²t²)

v₀ > 0이면 포물선 y = gx²/(2v₀²)을 그립니다.

03. 낙하 시간과 도달 거리

h = ½gT² → T = √(2h/g)

B의 수평 도달 거리 R = v₀√(2h/g)

h=20 m, g=10 m/s², v₀=10 m/s라면 T=2 s, R=20 m입니다. 질량과 수평 속력은 낙하 시간에 영향을 주지 않습니다.

04. 잔상으로 알아보는 운동

같은 시간 간격의 수평 이동 거리는 일정하고, 연직 이동 거리는 점차 증가합니다. 정지 상태에서 시작하면 연속된 같은 시간 간격의 낙하 거리 비는 1:3:5:7…입니다.

실험 화면의 마지막 잔상은 정규 간격까지만 표시됩니다. 실제 착지 위치는 물체 자체로 확인합니다.

05. 직접 탐구하기

① 높이 20 m, g=10으로 설정하고 B 속력을 5, 10, 20 m/s로 바꿔 보세요. 낙하 시간은 2초로 동일합니다.

② 높이를 5 m에서 20 m로 4배 늘리면 낙하 시간은 2배가 됩니다.

③ A와 B 질량을 서로 다르게 바꿔도 낙하 시간과 연직 가속도는 변하지 않습니다. 중력의 크기만 달라집니다.

06. 오개념과 실제 현상

수평으로 던진 물체가 더 오래 날아갈 것 같아도, 같은 높이에서 동시에 출발하면 이상적 조건에서는 동시에 도착합니다. B의 전체 속력은 더 크지만 연직 속도는 A와 같습니다.

실제 공기 저항은 속도·형상·공기 밀도 등에 의존하므로 결과가 달라질 수 있습니다. 본 실험은 공기 저항이 없는 모형이며 충돌 이후 운동은 다루지 않습니다.
