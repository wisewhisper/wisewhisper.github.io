일시정지는 화면 재생을 멈추며, 해당 실험 시각의 순간값을 유지합니다. 시각을 끌면 해당 순간을 관찰합니다.

변화 조건

조건 변경 시 시각은 0 s로 돌아가고 재생이 멈춥니다. 저장한 A·B 조건은 유지됩니다.

공식과 현재 값

기호·부호·렌츠 법칙

Φ는 한 바퀴를 통과하는 자기 선속(Wb), N은 감은 수, θ는 자기장과 코일의 양의 법선 n 사이 각도, ℰ는 코일 전체 유도 기전력(V)입니다. Φ 전체 합은 NΦ입니다.

양의 전류는 +n 쪽에서 코일을 바라볼 때 반시계 방향입니다. 양의 전류는 +n 방향 자기장을 만듭니다. ℰ의 음수 부호는 유도 자기장이 외부 선속의 변화를 방해함을 뜻합니다. 외부 자기장 자체를 항상 반대로 만드는 것은 아닙니다.

저항 R인 닫힌 회로에서 I = ℰ/R로 계산합니다. 회전 모드에서는 코일과 함께 움직이는 +n을 기준으로 부호를 정의합니다.

시간 그래프 · 한 바퀴 선속

실선: 설정한 전체 실험 과정 · 점: 현재 시각

시간 그래프 · 유도 기전력

종료 시 변화가 멈춰 기전력이 0 V가 됩니다. 선속 곡선의 기울기와 비교하세요.

같은 시각에서 조건을 저장하면 변수의 영향을 비교하기 쉽습니다.

값은 저장한 순간의 스냅샷입니다. 각 조건의 변화 범위·기간·N·R을 함께 표시합니다.

예측하고 설명하기

기본 · 자기장이 세면 전류가 항상 흐를까요?

‘선속 일정’을 누른 뒤 재생하세요. B = 0.5 T, A = 0.1 m², θ = 0°일 때 선속과 기전력을 예측하세요.

해설 보기

Φ = 0.05 Wb이지만 dΦ/dt = 0이므로 ℰ = 0 V, I = 0 A입니다. 자기장의 존재와 선속의 변화는 다릅니다.

응용 · 감은 수와 변화 시간을 바꾸면?

B를 0 T에서 1 T까지 10 s 동안 바꾸세요. N = 100, A = 0.1 m², θ = 0°에서 A를 저장하고 N을 두 배로 바꿔 같은 시각에 B를 저장하세요. 이어 기간을 5 s로 줄이면 어떻게 될까요?

해설 보기

처음 ℰ = −1 V입니다. N을 두 배로 하면 −2 V입니다. 같은 선속 변화를 절반의 시간에 만들면 |dΦ/dt|가 두 배가 되므로 기전력 크기도 두 배입니다. R이 같으면 전류 크기도 두 배입니다.

도전 · 선속이 0인 순간, 기전력도 0일까요?

회전 모드에서 B = 0.5 T, A = 0.1 m², N = 100, θ₀ = 0°, 각속도 = 90°/s로 설정하세요. 1 s와 2 s에서 선속과 기전력을 비교하고 전류 방향을 설명하세요.

해설 보기

회전 중 ℰ = NBAω sinθ입니다(ω 단위는 rad/s). 1 s에는 θ = 90°, Φ = 0이지만 ℰ ≈ +7.854 V로 최대입니다. 2 s에는 θ = 180°, Φ = −0.05 Wb이지만 순간 기울기는 0이므로 ℰ = 0입니다. 선속의 값과 변화율은 다릅니다.

오개념 확인 · 유도 자기장은 늘 외부 자기장에 반대?

B가 양수인 상태에서 감소하도록 설정하면 ℰ가 양수가 됩니다. 유도 자기장은 +n 방향으로 생겨 줄어드는 양의 선속을 보충합니다. 증가하는 경우에는 반대로 작용합니다.

적용 조건과 모형의 한계

균일한 외부 자기장, 평면 코일, 모든 감은 고리의 동일한 선속을 가정합니다. 회전 각속도와 면적·자기장의 변화율은 실험 구간에서 일정합니다. 선속은 Φ = ∫B·dA의 균일장 특수형입니다.

코일의 자체 유도, 상호 유도, 전기용량, 접촉 저항과 복잡한 기계 운동은 무시합니다. 총 저항 R만 고려한 준정적 모형이며 급격한 시작·종료의 실제 과도 전류를 재현하지 않습니다. 외부 장치가 변화 조건을 유지하고 유도 전류에 따른 반작용을 감당한다고 가정합니다.

회전 코일의 정면 그림은 언제나 +n 쪽에서 본 개념도입니다. 원의 크기·전류 화살표는 실제 크기·속도가 아니며, 자기장 기호는 B cosθ의 부호를 표시합니다. 면적 변화의 실제 도선 운동과 발전기의 상세 구조는 생략합니다. 저항에서 소비되는 에너지는 외부 변화 장치의 일에서 공급됩니다.
