개념 정리: 연속된 두 파동이 만나면 어떻게 될까?

1. 파원은 계속 진동한다

왼쪽 파원 A(x = −5λ)는 오른쪽으로, 오른쪽 파원 B(x = +5λ)는 왼쪽으로 같은 진폭 A, 파장 λ, 주기 T, 속력 v의 정현파를 끊임없이 발생시킵니다. 처음에는 각 파동의 앞부분이 떨어져 있지만, t = 3T에 중앙에서 처음 만나고, t ≈ 8T 이후에는 두 파동이 전 영역에서 중첩됩니다.

2. 합성파는 변위의 합이다

같은 위치 x, 같은 시간 t에서 각 파동의 변위를 부호까지 포함하여 더합니다. 파동은 충돌해 반사되는 것이 아니라 서로 통과해 본래 진행 방향으로 계속 갑니다.

3. 보강점과 상쇄점

같은 위상일 때 공간에 고정되는 배(antinode)에서는 진폭이 2A이고, 마디(node)에서는 변위가 늘 0입니다. 2A는 항상 위로 2만큼 올라가 있다는 뜻이 아니라, 그 지점이 진동하며 도달할 수 있는 최대 변위의 크기를 의미합니다.

4. ¼주기로 움직여 관찰

완전 중첩 상태에서 배의 순간 변위는 0 → +2A → 0 → −2A → 0 순서로 바뀔 수 있습니다. 반면 마디의 변위는 항상 0이며, 이 차이가 정상파의 핵심 특징입니다.

수학적 관계 (동일 위상·양쪽 동일 진폭, 중첩 영역)

yA(x,t) = A sin[2π(t/T − x/λ − 3)] yB(x,t) = A sin[2π(t/T + x/λ − 3)] y합(x,t) = 2A sin[2π(t/T − 3)] cos(2πx/λ)

이 식은 두 파동이 이미 도달해 겹친 영역에 적용됩니다. 아직 파동이 도달하지 않은 지점의 변위는 0입니다. 시간의 기준은 양쪽 파동이 t = 0일 때 이미 파원에서 2λ만큼 진행한 상태로 잡았습니다.

마디와 배의 위치

배: x = nλ/2 (n은 정수), 최대 진폭 2A. 마디: x = (2n+1)λ/4, 항상 변위 0. 이웃한 마디 사이 거리와 이웃한 배 사이 거리는 모두 λ/2입니다.
